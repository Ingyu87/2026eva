# 보완 기능 및 운영 인수 확인

## 이번 보완

- 문항 선택 화면에 교육목표·응답자 경험·중복 문항·영역 누락 확인 요령 추가.
- 결과 화면에 고정 단계 이동 버튼과 접기·펼치기 추가. 접어도 입력 내용은 유지.
- 의견의 결과·원인·개선방안 작성 요령과 가상 예시 제공. 예시를 실제 결과로 복사하지 않도록 표시.
- 집계 이름, 검토 메모, 내부 확인 체크 저장·복원. 학교 담당자만 수정 가능하며 오래된 내용으로 덮어쓰면 409 반환.
- 의견을 다시 저장하면 확인 체크만 해제. 메모는 유지. 검토 기록은 공식 제출 문서에 추가하지 않음.
- 한글·Word에서 편집한 파일과 앱의 데이터가 자동 동기화되지 않는다는 점을 명시.
- 관리자 화면에서 저장소·로그인 서명·Google OAuth·XLSX 양식의 설정 상태 확인. 비밀값은 반환하지 않으며 실제 연결 검증과 구분.

## 현재 환경에서 확인한 범위

Firebase 서비스 계정, Google OAuth, SESSION_SECRET은 이 PC의 환경변수에 미설정이다. 실제 운영 DB·Forms 검증은 설정 후에 가능하다. 한컴 한글 2010(8.5.8.1677) 실행 파일은 설치되어 있으나 이번 세션은 네이티브 앱 조작을 지원하지 않아 실제 열기·편집·재저장 검증을 수행하지 못했다. 이전 LibreOffice DOCX 렌더링 검증을 한컴 검증으로 대체해서 표시하지 않는다.

이번 보완으로 실제 사람의 만족도나 호환성을 다시 측정한 것은 아니므로 기존 내부 점수를 올려 기재하지 않는다.

## 보완 기능 검증 기록 (2026-09-19)

- 정적 검증: 타입 검사, 문항 풀 12개, 디자인 규칙 6개, 점수 계산 19개, 제출 조건 6개, 의견 검증 10개 통과.
- 운영 설정 판별: 미설정·잘못된 JSON·일부 설정·정상 설정·비밀값 비노출 검증 통과.
- API 통합 검증 36/36, 동시 편집 검증 22/22 통과. 검토 기록 저장·복원, 오래된 저장 거부, 학교별 접근 제한, 의견 저장 후 확인 체크 해제 포함.
- 관리자 설정 확인 API: 로그인 전 접근 거부 및 로그인 후 설정 상태 조회 확인.
- 1280×720 브라우저: 단계 이동, 검토 기록 접기·펼치기 시 입력 유지, 저장 성공 표시, 새로고침 후 이름·메모·체크 복원 확인.
- 배포용 `npm run build` 통과.

## 실제 사용자 인수 시나리오

실제 학생·학부모 자료 대신 가상 학교와 가상 응답을 사용한다. 관찰자는 먼저 설명하지 않고, 도움을 요청한 단계와 오류 내용을 기록한다.

| 대상 | 수행할 작업 | 통과 기준 |
|---|---|---|
| 처음 업무를 맡은 부장 | 문항 선택 요령을 읽고 학생용 관련 문항을 검색·담기·수정 | 교원용과 혼동하지 않고 선택 이유를 설명할 수 있음 |
| 웹앱 초보 부장 | 받은 링크로 담기·제출 후 다시 접속 | 작업이 유지되고 저장·제출 상태를 구분함 |
| 담당자 | 가상 응답 파일의 열을 연결하고 집계 이름 지정 | 제외한 열의 이유를 이해하고 이름으로 집계를 다시 찾음 |
| 검토위원 | 의견·근거를 대조하고 메모와 확인 체크 저장 | 다시 열었을 때 기록 유지, 의견 수정 후 체크 해제 확인 |
| 디자인 중시 사용자 | 각 단계를 접고 이동하며 작성 | 주요 버튼 잘림 없이 접었던 입력 내용을 다시 확인 |
| 한글 선호 사용자 | 작성용 DOCX 열기·다른 이름 저장·수정·재열기 | 마지막 문항·표 머리글·쪽 경계·수정 문장 보존 |
| 장학 담당 검토자 | 가상 결과와 공식 양식 대조 | 전 영역·평가주체, 점수 판정, 제출용 문항별 점수 제외 확인 |

## 운영 연결 확인 순서

1. 운영 환경변수에 Firebase·SESSION_SECRET·Google OAuth를 설정한다. 비밀값을 저장소나 검토 문서에 적지 않는다.
2. 관리자 ‘운영 준비 확인’에서 설정 유무를 확인한다.
3. 가상 학교에서 저장·로그아웃·재로그인·다른 브라우저 동시 편집을 확인한다.
4. 가상 학생용 Google Forms를 생성하고 학년 선택, 선택형·서술형 문항을 확인한다.
5. 2026 교육청 빈 XLSX 양식을 등록하고 가상 집계의 값·수식·병합을 원본과 대조한다.
6. 설치된 한글·Word 버전별로 DOCX 인수 시나리오를 수행하고 프로그램 버전과 결과를 기록한다.

이 문서는 시험 절차이며 실제 사용자 시험이나 운영 연결 시험이 완료됐다는 기록이 아니다.
