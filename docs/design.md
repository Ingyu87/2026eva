# design.md — 디자인 시스템

- 기준: **서울특별시교육청 클래스보드** 화면 스타일
- 적용 대상: 2026 학교평가 웹앱 전체 화면
- 마지막 수정: 2026-09-18

> **이 문서의 역할**
> "눈에 보이는 것"만 정합니다. 색·크기·간격·모양.
> 버튼을 누르면 무슨 일이 생기는지는 `spec.md`에 있습니다.

> **색상값 주의**
> 아래 값은 제공된 화면 캡처에서 추출한 것입니다.
> 실제 서비스와 정확히 맞춰야 한다면 브라우저 개발자도구로 한 번 대조해 확정하세요.
> 확정 전까지는 이 문서가 기준입니다.

## 1. 전체 인상

이 스타일을 한 줄로 요약하면 **"연보라 배경 위에 떠 있는 흰 카드"** 입니다.

- 배경은 흰색이 아니라 **아주 연한 남보라**입니다. 그 위에 흰 카드가 떠 보입니다.
- 모서리는 **넉넉하게 둥급니다** (12~20px). 각진 데가 거의 없습니다.
- 그림자는 **아주 옅습니다.** 카드가 붕 떠 보이지 않고 살짝만 들려 있습니다.
- 선(테두리)은 **연한 회색**이고 얇습니다.
- 강조는 **남보라(인디고)** 한 가지로만 합니다. 색을 여러 개 쓰지 않습니다.

## 2. 색상

### 2.1 브랜드 색 (남보라 계열)

```css
--brand-900: #2E2E86;   /* 가장 진한 강조 (헤더 띠 등) */
--brand-700: #3B3AA8;   /* 진한 강조, 활성 메뉴 */
--brand-600: #4341C4;   /* ★ 기본 버튼, 링크, 활성 탭 */
--brand-500: #5B54E0;   /* 밝은 강조 */
--brand-200: #C9C7F3;   /* 옅은 테두리 */
--brand-100: #E8EAFB;   /* ★ 뱃지·태그 배경 */
--brand-050: #F2F3FD;   /* 아주 옅은 강조 배경 */
```

**`--brand-600`이 이 앱의 대표색입니다.** 버튼·활성 탭·선택 상태는 전부 이 색입니다.

### 2.2 배경

```css
--bg-page:   #EEF0F9;   /* ★ 페이지 전체 바탕 (흰색 아님) */
--bg-card:   #FFFFFF;   /* 카드 안쪽 */
--bg-subtle: #F5F6FA;   /* 카드 안의 한 단계 들어간 영역(안내문 박스 등) */
--bg-soft:   #F2F6FD;   /* 아주 연한 파랑 (과목 카드 등) */
--bg-overlay: rgba(23, 23, 46, 0.45);  /* 모달 뒤 어두운 막 */
```

배경에는 **연분홍·연보라 큰 원**이 아주 흐리게 깔려 있습니다. 선택 사항입니다.

```css
/* 배경 장식 (선택) */
body::before  { /* 좌상단 */ background: radial-gradient(closest-side, #F7DCE9 0%, transparent 100%); }
body::after   { /* 우상단 */ background: radial-gradient(closest-side, #DCD8F6 0%, transparent 100%); }
```

### 2.3 글자

```css
--text-strong: #16161D;   /* 제목 */
--text-body:   #333340;   /* 본문 */
--text-muted:  #6B7080;   /* 설명, 보조 */
--text-faint:  #9AA0B0;   /* 비활성, placeholder */
--text-onbrand:#FFFFFF;   /* 남보라 위 글자 */
```

### 2.4 선

```css
--line-strong: #D8DBE5;   /* 카드 테두리 */
--line:        #E6E8EF;   /* ★ 기본 구분선 */
--line-soft:   #F0F1F6;   /* 표 안쪽 줄 */
```

### 2.5 상태 색

```css
--ok:      #16A34A;   /* 저장됨 */
--warn:    #F59E0B;   /* 주의 */
--danger:  #EF4444;   /* ★ 오류, 알림 뱃지 */
--info:    #2563EB;   /* 안내 */

--ok-bg:     #E9F7EF;
--warn-bg:   #FEF5E7;
--danger-bg: #FDECEC;
--info-bg:   #E8F1FE;
```

### 2.6 그라데이션 (강조 카드 1개에만)

```css
--grad-hero: linear-gradient(135deg, #6C5CE7 0%, #5145CD 100%);
```

메인 화면의 대표 카드 딱 하나에만 씁니다. 여러 곳에 쓰면 촌스러워집니다.

### 2.7 다크 모드

**지원하지 않습니다.** 24인치 모니터 밝은 사무실 환경 고정입니다.

## 3. 글꼴

```css
--font: "Pretendard", "Pretendard Variable", -apple-system,
        "Malgun Gothic", "맑은 고딕", sans-serif;
```

| 이름 | 크기 | 굵기 | 줄간격 | 쓰는 곳 |
|---|---|---|---|---|
| `page-title` | 24px | 700 | 1.35 | 화면 제목 ("수업도구 설정") |
| `section-title` | 18px | 700 | 1.4 | 카드 제목 ("클래스", "도구모음") |
| `group-title` | 15px | 700 | 1.45 | 카드 안 소제목 ("LMS 사용 설정") |
| `body` | 14px | 400 | 1.6 | 본문 |
| `body-strong` | 14px | 600 | 1.6 | 강조 본문, 메뉴 |
| `small` | 13px | 400 | 1.55 | 보조 설명 |
| `caption` | 12px | 500 | 1.5 | 뱃지, 라벨 |

## 4. 간격 · 모양

### 4.1 간격 (4px 배수만 사용)

```css
--sp-1: 4px;    --sp-2: 8px;    --sp-3: 12px;   --sp-4: 16px;
--sp-5: 20px;   --sp-6: 24px;   --sp-8: 32px;   --sp-10: 40px;
```

**규칙: 이 8개 값 외에는 쓰지 않습니다.** `13px`, `17px` 같은 값이 섞이면 화면이 어긋나 보입니다.

- 카드 안쪽 여백: `24px` (작은 카드는 `16px`)
- 카드끼리 간격: `20px`
- 섹션끼리 간격: `32px`

### 4.2 모서리 둥글기

```css
--r-sm:   8px;    /* 뱃지, 작은 입력창 */
--r-md:   12px;   /* ★ 버튼, 작은 카드, 탭 */
--r-lg:   16px;   /* ★ 큰 카드, 모달 */
--r-xl:   20px;   /* 대표 카드 */
--r-full: 999px;  /* 검색창, 토글, 필 */
```

### 4.3 그림자

```css
--sh-card:  0 1px 2px rgba(22, 22, 45, 0.04),
            0 4px 12px rgba(22, 22, 45, 0.05);   /* ★ 카드 기본 */
--sh-hover: 0 2px 4px rgba(22, 22, 45, 0.06),
            0 8px 20px rgba(22, 22, 45, 0.08);   /* 마우스 올렸을 때 */
--sh-modal: 0 20px 60px rgba(22, 22, 45, 0.20);  /* 모달 */
```

**그림자는 이 3개뿐입니다.** 진한 그림자는 쓰지 않습니다.

## 5. 화면 뼈대

> **클래스보드에서 가져오는 것과 안 가져오는 것**
>
> 이 앱은 화면이 6개뿐이고, 그중 작업 화면 하나가 거의 전부입니다.
> 메뉴가 수십 개인 포털이 아니므로 **뼈대는 따라가지 않습니다.**
>
> | 클래스보드 요소 | 채택 | 이유 |
> |---|---|---|
> | 색·타이포·간격·그림자 | ✅ | |
> | 버튼·카드·탭·토글·뱃지·표·입력창 | ✅ | |
> | 상단바 | ✅ | 여기에 화면 전환 탭을 넣음 |
> | 좌측 사이드바 232px | ❌ | 3열 작업화면에 가로 폭을 다 써야 함 |
> | 전체 메뉴 모달 | ❌ | 메뉴가 6개뿐 |
> | 브레드크럼 | ❌ | 화면 깊이가 2단계뿐 |
> | FAB(맨 위로) | ❌ | 페이지 스크롤이 없으므로 무의미 |

```
┌──────────────────────────────────────────────────────────────────┐
│  상단바  높이 64px  흰색  아래 1px 선                               │
│  [학교명] [화면 탭] ······· [저장 상태] [접속자] [설정] [출력▾]      │
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│   본문 영역   배경 --bg-page   좌우 여백 24px                       │
│   높이 = 100dvh − 64px                                            │
│                                                                  │
└──────────────────────────────────────────────────────────────────┘
```

```css
--h-topbar: 64px;
--pad-content: 24px;
```

### 중요: 세로 스크롤 금지

작업 화면(문항 고르기)은 **전체 높이를 화면에 꽉 채우고, 안쪽 열만 스크롤**합니다.

```css
.workspace {
  height: calc(100dvh - var(--h-topbar));
  display: grid;
  grid-template-columns: 22% 1fr 34%;
  gap: var(--sp-5);
  overflow: hidden;              /* 페이지 자체는 절대 스크롤 안 함 */
}
.workspace > * {
  min-height: 0;                 /* 이게 없으면 열이 안 줄어듭니다 */
  overflow-y: auto;
}
```

> ⚠️ **기존 코드의 `max-height: 620px` / `500px` 같은 고정값은 전부 제거합니다.**
> 24인치 모니터에서 아래가 텅 비는데 카드 안에서 스크롤하는 원인입니다.

## 6. 부품 규격

### 6.1 상단바

사이드바가 없으므로 **네비게이션도 여기서** 합니다.

```
[🏫 서울가동초] │ [문항 구성][결과 분석][내보내기] ········ [✔저장됨 14:32] [👥2] [⚙] [↪]
     좌측              중앙(화면 전환 탭)                        우측(상태·도구)
```

- 높이 `64px`, 배경 흰색, 아래 `1px solid var(--line)`, 좌우 여백 `24px`
- **좌측** — 학교명 `body-strong` `--text-strong`. 앞에 작은 아이콘
- **중앙 — 화면 전환 탭**
  - 알약 묶음(`--r-full`) 안에 버튼 3개. 배경 `--bg-subtle`, 패딩 `3px`
  - 활성: 배경 `--brand-600`, 흰 글자. 비활성: `--text-muted`
  - 높이 `34px`, 좌우 여백 `16px`, `body-strong`
  - 잠긴 탭(중간평가 모드의 `내보내기` 등)은 `opacity:.45` + 마우스 올리면 이유 툴팁
- **우측**
  - 저장 상태 배지 → 7.2
  - 접속자 `👥 2` — 마우스 올리면 이름과 보고 있는 대상 표시
  - `⚙` 설정 모달 · `↪` 로그아웃 — 각 `36×36px`, `--r-md`, hover `--bg-subtle`

> 검색창은 상단바가 아니라 **작업 화면 가운데 열 상단**에 둡니다 (7.1).
> 화면마다 검색 대상이 다르고, 가장 많이 쓰는 곳 바로 위에 있어야 합니다.

### 6.2 대상 탭 (작업 화면 전용)

교원 / 학부모 / 학생 / 직원 전환. 작업 화면 본문 **맨 위 줄**에 둡니다.

- 밑줄형 탭. 높이 `40px`, 좌우 여백 `16px`
- 활성: `--text-strong` 굵게 + 아래 `2px solid var(--brand-600)`
- 비활성: `--text-muted`
- 각 탭 오른쪽에 담긴 문항 수 뱃지(`.pill`)
- 영역 커버리지 미충족이면 뱃지를 `--danger-bg` 로

### 6.3 카드

```css
.card {
  background: var(--bg-card);
  border: 1px solid var(--line);
  border-radius: var(--r-lg);
  box-shadow: var(--sh-card);
  padding: var(--sp-6);
}
```

**카드 머리**: 좌측 `section-title`, 우측 액션 버튼(있으면).

```
클래스                                    [⚙ 클래스 순서 설정]
```

### 6.4 소제목 (세로 막대형)

카드 안에서 단락을 나눌 때 씁니다.

```
▌LMS 사용 설정
```

```css
.group-title::before {
  content: ""; width: 3px; height: 16px;
  background: var(--brand-600); border-radius: 2px;
  margin-right: var(--sp-2);
}
```

### 6.5 안내 박스

```
ⓘ  교육청에서 기본적으로 제공되는 LMS 중, …
    사용 off 설정 시, 해당 LMS는 …
```

```css
.notice {
  background: var(--bg-subtle);
  border-radius: var(--r-md);
  padding: var(--sp-4);
  color: var(--text-muted);
  font-size: 13px;
}
```
아이콘은 `--text-faint` 원형 ⓘ.

### 6.6 버튼

| 종류 | 배경 | 글자 | 테두리 | 쓰는 곳 |
|---|---|---|---|---|
| **주요** | `--brand-600` | 흰색 | 없음 | 저장, 만들기, 출력 |
| **보조** | 흰색 | `--text-body` | `1px --line-strong` | 설정, 취소 |
| **연한** | `--brand-050` | `--brand-600` | 없음 | 카드 머리 액션 |
| **위험** | 흰색 | `--danger` | `1px --danger` | 삭제 |
| **텍스트** | 없음 | `--text-muted` | 없음 | 부가 동작 |

```css
.btn {
  height: 40px; padding: 0 16px;
  border-radius: var(--r-md);
  font: 600 14px/1 var(--font);
  display: inline-flex; align-items: center; gap: 6px;
  transition: background .15s, box-shadow .15s;
}
.btn-sm { height: 32px; padding: 0 12px; font-size: 13px; }
.btn-lg { height: 48px; padding: 0 24px; font-size: 15px; }
```

### 6.7 탭

```
[ 도구모음 설정 ]  즐겨찾는 수업도구
──────────────────────────────────
```

- 위쪽만 둥글게: `12px 12px 0 0`
- 활성: 흰 배경 + 좌·우·위 테두리, 아래쪽은 본문 카드와 이어짐, 글자 `--text-strong` 굵게
- 비활성: 투명 배경, 글자 `--text-muted`
- 높이 `44px`, 좌우 여백 `20px`

### 6.8 토글 (ON / OFF)

```
[ ON ] OFF        ← ON 상태
 ON [ OFF ]       ← OFF 상태
```

두 칸짜리 알약 모양입니다. 켜짐/꺼짐이 **글자로 보이는 게** 이 스타일의 특징입니다.

```css
.toggle { display: inline-flex; background: var(--bg-subtle);
          border-radius: var(--r-full); padding: 3px; }
.toggle button { height: 28px; padding: 0 14px; border-radius: var(--r-full);
                 font: 600 13px/1 var(--font); color: var(--text-faint); }
.toggle button[aria-pressed="true"] { background: var(--brand-600); color: #fff; }
/* OFF가 선택된 경우 */
.toggle button.off[aria-pressed="true"] { background: #8A8F9E; }
```

### 6.9 그리드 카드 (아이콘 + 이름 + 조작)

도구모음처럼 격자로 늘어놓는 카드입니다.

```css
.grid-cards { display: grid; grid-template-columns: repeat(4, 1fr); gap: var(--sp-4); }
.grid-card  { border: 1px solid var(--line); border-radius: var(--r-md);
              padding: var(--sp-4); background: #fff; }
.grid-card:hover { box-shadow: var(--sh-hover); border-color: var(--brand-200); }
```
- 이름은 좌상단, 아이콘은 우상단 `40×40px`
- 조작 요소(토글/버튼)는 좌하단

### 6.10 뱃지 · 필

```css
.pill { height: 24px; padding: 0 10px; border-radius: var(--r-full);
        font: 500 12px/1 var(--font);
        background: var(--brand-100); color: var(--brand-700); }
.pill-ok     { background: var(--ok-bg);     color: var(--ok); }
.pill-danger { background: var(--danger-bg); color: var(--danger); }
```

### 6.11 입력창

```css
.input {
  height: 40px; padding: 0 12px;
  border: 1px solid var(--line-strong); border-radius: var(--r-md);
  background: #fff; font: 400 14px/1 var(--font);
}
.input:focus { border-color: var(--brand-600);
               box-shadow: 0 0 0 3px var(--brand-100); outline: none; }
.input::placeholder { color: var(--text-faint); }
```

**검색창만 예외**로 `--r-full`(알약 모양)입니다.

### 6.12 표

```css
.table th { background: var(--bg-subtle); font: 700 13px/1.4 var(--font);
            color: var(--text-body); height: 44px; }
.table td { border-bottom: 1px solid var(--line-soft); height: 48px; font-size: 14px; }
.table tr:hover td { background: var(--brand-050); }
```
- 바깥 테두리는 없애고 **가로줄만** 둡니다
- 숫자는 오른쪽 정렬, 글자는 왼쪽 정렬

## 7. 학교평가 앱 전용 화면 규격

일반 부품을 조합해 만드는, 이 앱에만 있는 화면입니다.

### 7.1 문항 고르기 작업 화면 (핵심 화면)

```
┌ 상단바 64px ────────────────────────────────────────────────────────┐
│ 서울가동초 │ [문항구성][결과분석][내보내기] │ ✔저장됨 14:32 │👥2│ ⚙ │ ↪ │
├─────────────────────────────────────────────────────────────────────┤
│ 교원 12 │ 학부모 9 │ 학생 8 │ 직원 5          ← 대상 탭 (40px)        │
├───────────────┬────────────────────────────┬────────────────────────┤
```

**대상 탭** — 6.2 규격. 상단바가 아니라 **본문 맨 위 줄**입니다.

**지표 트리**
- 배경 흰색 카드, 3단 들여쓰기 (`0` / `16px` / `32px`)
- 각 항목 우측에 문항 수 뱃지(`.pill`)
- 선택된 항목: 배경 `--brand-050` + 좌측 `3px` 막대 `--brand-600`
- 문항이 0개인 항목은 `--text-faint`

**문항 후보 카드**
- `1px solid var(--line)`, `--r-md`, 여백 `16px`
- 1행: 평가지표명 (`caption`, `--brand-600`)
- 2행: 문항 본문 (`body`)
- 마우스 올리면 우하단에 `＋ 담기` 버튼 등장 + 그림자 `--sh-hover`
- **이미 담은 문항**: 배경 `--bg-subtle`, 우상단에 `✔ 담김` 뱃지, 클릭 불가
- 검색어와 일치하는 글자는 `<mark>` 로 강조 (배경 `#FFF3BF`)

**선택 문항 카드**
- 좌측에 번호(화면에서 계산한 값)
- 우측 아이콘 4개: 위로 `↑` / 아래로 `↓` / 수정 `✎` / 삭제 `✕` — 각 `28×28px`
- 드래그 손잡이는 카드 왼쪽 가장자리
- 다른 사람이 편집 중이면 우상단에 이름 뱃지 (`.pill`, `--warn-bg`)

**영역 커버리지 게이지**
- `Ⅰ ●●●` 처럼 영역별 충족 여부 표시
- 문항이 있으면 `--ok`, 없으면 `--danger` + ⚠ 아이콘 + 안내문
  (가이드북 Q9: 학생·학부모·교원은 Ⅰ·Ⅱ·Ⅲ 전 영역 필수)

### 7.2 저장 상태 표시

상단바 오른쪽에 **항상** 보입니다. 부장님들이 "저장됐나?"를 의심하지 않게 하는 장치입니다.

| 상태 | 표시 | 색 |
|---|---|---|
| 정상 | `✔ 저장됨 14:32` | `--ok` |
| 전송 중 | `↻ 저장 중…` (아이콘 회전) | `--text-muted` |
| 실패 | `⚠ 미전송 3건 · 재시도` (클릭 가능) | `--danger` + `--danger-bg` |
| 동시 작업 | `👥 2` (올리면 이름 목록) | `--brand-100` |

**이름은 어디서 오나** — 로그인 계정은 학교 단위 하나라 개인 이름이 없습니다.
로그인 직후 한 번 물어서 받은 **표시용 라벨**입니다 (`spec.md` 4.11).
라벨을 안 정했으면 `사용자 2` 처럼 익명 번호로 표시합니다.

## 10. 지키면 안 어긋나는 3가지

새 화면을 만들 때 이 3개만 확인하면 됩니다.

1. **색은 위 목록에서만 고른다.** 새 색을 쓰고 싶으면 이 문서에 먼저 추가합니다.
2. **간격은 4의 배수만 쓴다.** `13px` 같은 값이 보이면 잘못된 겁니다.
3. **강조색은 남보라 하나만 쓴다.** 초록·주황·빨강은 상태 표시에만 씁니다.
