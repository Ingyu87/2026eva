# Google Forms 실제 연결 점검 — 2026-09-19

가상 학교와 가상 문항 12개로 배포 사이트에서 확인했다. 실제 학교 응답은 사용하지 않았다.

## 확인한 장애

사용자가 Google 로그인과 동의를 완료했으나 문항 추가 요청이 HTTP 400 `Invalid ID`로 실패했다. 안내문 ID에 앱의 UUID를 붙여 보내는 부분에서 발생했다. 이 오류는 로그인 화면에만 표시되어 로그인 상태의 작업 화면에서는 보이지 않았다. 사용자의 인증 미완료로 판단해 다시 인증을 요청한 것은 잘못된 판단이었다.

## 수정

- 요청에서 문항 ID를 지정하지 않고 Google가 발급한 ID를 응답에서 받아 연결표에 저장한다. 학생 학년 문항도 같은 방식으로 연결한다.
- 연결 성공·실패 결과를 작업 화면에서도 확인 버튼을 누를 때까지 표시한다.
- 깨진 한국어 오류 문구를 수정한다.

`node scripts/verify-google-form-ids.cjs`와 `npm run verify`를 통과했다. 회귀 검사는 가짜 API 응답으로 ID 연결을 검증하므로 실제 Google Forms 생성 성공을 뜻하지 않는다. 수정 배포 후 실제 생성·응답·응답 파일 재집계를 추가 확인해야 한다.

## 수정 배포 후 실제 업무 검증

수정본 배포 완료 후 같은 Google 계정의 기존 권한으로 다음 과정을 수행했다.

- 교원·학부모·학생 폼 3개 생성 성공. Google 발급 ID와 앱 문항 연결표 저장 확인.
- 학생 폼의 학년 4·5·6 선택을 필수 문항으로 확인. 5점 척도·단일 선택·복수 선택·서술형에 실제 가상 응답 제출.
- 교원·학부모도 각각 가상 응답 1건 제출. Google 응답 화면에서 1건씩 확인.
- Google UI에서 CSV ZIP을 내려받아 압축 해제 후 웹앱 화면에서 3개 CSV 업로드. 학년과 문항 자동 연결 확인.
- 교원 5·5·5, 학부모 4·4·4, 학생 5·4·3으로 집계됨. 학생 4학년 분류 확인.
- 웹앱에서 가상 평가 의견 6개와 종합의견을 직접 작성·저장. 제출용 DOCX 생성 성공.
- DOCX를 LibreOffice로 PDF 변환하여 4쪽의 표, 판정 표시, 의견, 문항 목록을 확인. 별도 한컴 편집 검증과 구별한다.
- HTML 출력 성공 및 서술형 보존 확인. 복수선택 원본 `독서;체육`을 하나의 보기로 집계하는 장애 발견. 세미콜론 처리 수정 후 같은 실제 CSV로 HTML을 재생성해 독서·체육 분리 확인.

## 아직 배포 완료로 판단할 수 없는 항목

1. 운영 서버에 평가지표 및 현황 XLSX 템플릿이 없다. 실제 출력 API는 404와 관리자 양식 등록 안내를 반환했다. 검증용 또는 전년도 양식을 운영 공통 양식으로 임의 등록하지 않았다.
2. 작년 설문지 4개 추출 결과: 교원 41개, 학부모 37개, 직원 10개, 학생 27개. 교원 30·31번은 학년군별 선택 및 대안 입력을 묻는 표형 문항인데 각각 한 문항으로 추출됐고 유형은 미확정이다. 23번 학년군별 복수선택도 한 문항으로 합쳐졌다. 원문의 개별 응답 구조까지 자동 보존된 것으로 볼 수 없다.
3. 학교별 ‘기타’ 직접 입력, 복수선택 개수 제한, 특정 학년만 응답하는 분기까지 원문과 동일하게 자동 구성하는 기능은 이번 시험으로 보장하지 않는다.

PDF 표의 띄어쓰기·보기 번호·끝 마침표 때문에 동일한 5점 척도를 일반 선택형으로 분류하는 문제는 수정했다. 다른 의미의 척도 문구와 원문 보기 배열은 유지한다. CSV·XLSX 지원 및 ZIP 압축 해제 안내도 화면에 추가했다.

## 별도로 확인한 한컴 편집

가상 결과 DOCX를 한컴오피스 한글 2010에서 열고 가상 문장을 입력한 뒤 HWP 사본으로 저장했다. 닫고 다시 열어 수정 문장이 유지되는 것을 확인했다. 전체 제출 양식의 인쇄 품질 확인과는 구별한다.

## 후속 수정: 표형 문항과 학교별 XLSX 양식

- 표를 행별 구조로 추출하고 각 행의 선택 문항과 직접 입력 칸을 별도 문항으로 변환한다. Gemini와 Upstage에 같은 구조를 지정했다.
- 실제 교원용 PDF 재추출 결과 1~41번 원문 문항을 모두 포함한 53개 응답란이 생성됐다. 23번은 학년군별 복수선택 2개, 26번은 증·감 2개, 30·31번은 각각 선택 3개와 대안 입력 3개로 보존됐다. 유형 미확정은 0개였다. 이번 실제 추출은 Gemini로 확인했으며 Upstage 실호출은 미검증이다.
- 결과 화면에 학교가 받은 2026 XLSX 양식을 직접 선택하는 기능을 추가했다. 선택한 파일은 해당 출력에만 쓰고 공통 양식이나 다른 학교 데이터에 저장하지 않는다. 기존 GET 방식의 공통 양식 출력도 유지한다.
- 로컬 API 시험에서 관리자 등록 없이 양식 첨부→출력→파일 재열기를 확인했다. 문항 수, 등급, 학교명, 이전 값 제거, 합계 수식·병합 보존 등 12개 검사를 통과했다. 이 시험은 합성 양식으로 수행했다.
- **2026 교육청 공식 XLSX 원본은 아직 확보하지 못했다.** 폴더의 2025 파일을 올해 공통 양식으로 대체하지 않았다. 공식 양식 등록 및 그 원본을 이용한 제출 파일 검증은 남아 있다. 학교별 직접 선택 기능이 이 검증을 대신하지 않는다.
- 선택 개수 안내는 보존하지만 Google Forms의 개수 제한·조건부 분기 자동 설정은 지원하지 않는다. 가져오기 화면에 이 제한을 표시한다.
- `aef9cd8` 운영 배포 성공 후 기존 가상 학교의 집계 결과에 합성 양식을 첨부해 HTTP 200 출력과 파일 재열기를 확인했다. 학교명, 교원·학부모 등급, 미참여 직원 빈칸, 합계 수식을 검증했다. 운영 화면의 ‘교육청 양식 직접 선택’ 표시와 펼친 화면 배치도 확인했다.
