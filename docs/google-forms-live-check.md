# Google Forms 실제 연결 점검 — 2026-09-19

가상 학교와 가상 문항 12개로 배포 사이트에서 확인했다. 실제 학교 응답은 사용하지 않았다.

## 확인한 장애

사용자가 Google 로그인과 동의를 완료했으나 문항 추가 요청이 HTTP 400 `Invalid ID`로 실패했다. 안내문 ID에 앱의 UUID를 붙여 보내는 부분에서 발생했다. 이 오류는 로그인 화면에만 표시되어 로그인 상태의 작업 화면에서는 보이지 않았다. 사용자의 인증 미완료로 판단해 다시 인증을 요청한 것은 잘못된 판단이었다.

## 수정

- 요청에서 문항 ID를 지정하지 않고 Google가 발급한 ID를 응답에서 받아 연결표에 저장한다. 학생 학년 문항도 같은 방식으로 연결한다.
- 연결 성공·실패 결과를 작업 화면에서도 확인 버튼을 누를 때까지 표시한다.
- 깨진 한국어 오류 문구를 수정한다.

`node scripts/verify-google-form-ids.cjs`와 `npm run verify`를 통과했다. 회귀 검사는 가짜 API 응답으로 ID 연결을 검증하므로 실제 Google Forms 생성 성공을 뜻하지 않는다. 수정 배포 후 실제 생성·응답·응답 파일 재집계를 추가 확인해야 한다.

## 별도로 확인한 한컴 편집

가상 결과 DOCX를 한컴오피스 한글 2010에서 열고 가상 문장을 입력한 뒤 HWP 사본으로 저장했다. 닫고 다시 열어 수정 문장이 유지되는 것을 확인했다. 전체 제출 양식의 인쇄 품질 확인과는 구별한다.
